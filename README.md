# GH Quick Actions

A simple web extension that adds a set of predefined icons as quick actions to the GitHub "add PR comment" form

## Installation

As the extension is not (yet) published to the stores, you can install it manually:

- Firefox: (temporary) [extension installation guide](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/)
- Chromium-based: [loading an unpacked extension](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)
